C 进化仪表 / D 传记缩放按序完成（明细见 §9 分期表）。两张定稿图：

设计沿革（2026-10-14 晚四轮收敛）：
① **时间望远镜**——信息架构诊断：剧场 v2 是内容革命，但容器仍是管理后台
（NavRail + 8 tab + 三栏卡 + 设置页）；六个时间视图（泳道/日志流/分集/回看/
生命线/年轮条）应折叠为一个缩放轴。
② **居所**——用户点破六感意图："我设计了六感，我其实是在模拟真实人类"。
重读 perception.md 后，界面组织轴从软件域（路由/设置/配置）换成生命域
（新陈代谢/感官/记忆/作息/手艺/社交/传记）。
③ **师承**——用户最终纠偏：「我不是管理员，但也不是共居者+照护者+雇主。
应该是**老师+伙伴+主人**，喂它、教它、委托它的目的是为了让它能够成长成为
**我的数字分身**，它最终是为我服务。」陪伴是过程，分身是目的。
④ **同行**（同日深夜再修）——用户修正关系表述：「用师徒来描述关系不太合适，
其实是**互相成就和共同成长**的过程，并不是单向的教学。」据此：师承曲线更名
**同行曲线**，师徒面更名**同行面**，阶段更名 **起步期→同行期→分身期**（原
学徒期/伙伴期），教学账改为**共同成长账**（双向记账），并新增双向性原则
（§4.0）。"学习期/转正"等机制词不动（perception.md 机制名）。

本稿合并三轮。关联：`theater.md`（舞台/五态/审批增补——全部继承）、
`ui-language.md`（年轮 token/三声部/格纸——视觉底座保留）、`perception.md`

## 3. 形态篇：生命体解剖（定稿图一）

### 3.1 六根与生命系统 → 界面面映射

中央是**意**（思考者，已有）；环绕眼/耳/鼻/舌/身（perception 已全数落地）+
内感（sensor/self）；外围是生命系统环，每个系统一个界面面：

| 生命系统 | 机制事实源 | 界面面 | 形态 |
|---|---|---|---|
| 新陈代谢 | 预算水位/分账/效率（usage、obs） | **食量** | 喂养读数：吃了多少、消化率、饿不饿（80% 水位=琥珀）；调预算=喂食，是照护动作不是计费设置 |
| 睡眠与梦 | S0 沉淀、quiet 窗、idle 呼吸（五态已有） | **睡眠** | 睡眠可见：无唤醒窗口即安睡，S0 消化即"做梦"（睡眠整理落地后如实呈现） |
| 作息 | schedule.json（巡逻/汇报/quiet 时段） | **作息** | 习惯节律视图：什么时候巡逻、什么时候汇报——像看一个人的课表 |
| 注意力 | event 步骤流（S0-S3 已落轨迹） | **感知** | "它正在看什么、听见了什么、什么被安静略过"——视觉分级复用神经系统：S0 几乎不可见、S1 一行、S2 一张卡 |
| 手艺 | skills + 触觉经验沉淀（Phase 5） | **手艺** | 学习面：装技能=教一门手艺，触觉经验=它自己练出的手感 |
| 社交 | channels + webhook | **社交** | 它认识谁、通过谁说话、谁按了门铃（webhook=耳） |
| 体检 | llm-health + 熔断冷却 | **体检** | 身体读数+病史（冷却=生病休养，语义已有） |
| 传记 | 轨迹 + recap + 周报管道 | **日记** | 一生记述；回看=翻传记（§5） |
| 手账 | memories + mem-recall 台账 | **手账** | 它记得的事（衬线"写"声部）；修订=改口，失效=忘了；召回台账=它此刻想起什么 |

### 3.2 隐喻机制账（真伪标准，perception §1 反用）

**每多一个生命隐喻必须挣到一个已存在机制，否则砍词。** 全部隐喻禁止虚构：
饿是真的饿（水位 80%）、疼是真的疼（熔断）、睡是真的睡（无唤醒窗口）、
忘了是真的失效（invalidate）。界面上不出现任何机制不支撑的拟人词。

### 3.3 三化身同源

**脸**（桌宠，用户拍板的生物形态）、**身**（舞台宇宙核心球）、**星**
（多心智星系里的一颗星，§6.3）——同一份五态参数驱动（idle/working/
等审批/出错/冷却），一只生命在三个距离上的样子。pet 机制零改，仅表现层
共享五态派生（`pet-state.ts` 与 scene-cosmos 五态参数同源化）。

### 3.4 体征层

一条跨视图常驻的生命体征带（呼吸/心跳/食量/睡眠/痛觉），数据全部来自
五态派生 + usage 水位 + llm-health + sensor/self 内感受。任何时候瞥一眼，
都知道它"活着没有、饿不饿、疼不疼"。

## 4. 进化篇：同行曲线（定稿图二，原名师承曲线）

### 4.0 双向性原则（2026-10-14 深夜用户修正）

关系不是单向教学，是**互相成就、共同成长**：用户给它方向、边界与养料，
它给用户杠杆、反馈与陪伴——**它也在改变用户**（重复检查的习惯交给它后，
用户的精力上移到架构与裁决）。因此：

- 界面永远双向记账：共同成长账同时记"它为用户做的"与"用户为它做的"，
  以及"一起长出来的"（§6.2）；
- 禁止单向叙事：不把它写成受教的工具，也不写成无主流浪——两个同行者，
  一段路上它从起步走到替用户出面；
- 机制词不动：学习期/转正（perception.md）是机制名，不随关系词更名。

### 4.1 三阶段

```
起步期（用户多引导：批改·纠错·示范）
  → 同行期（并肩：委托·商量·分工）
    → 分身期（它多担当：替用户出面·为用户服务）
```

- **阶段不是等级称号，是自主权边界的当前快照**；
- **推进只靠用户放权**，不靠积分攒满——主动权始终在用户手里；
- 阶段名原为 学徒期/伙伴期（师承曲线图已获采纳），2026-10-14 深夜随关系
  修正更名（沿革④）——阶段描述的是**自主度**，不是师徒身份。

### 4.2 三轴与机制映射

| 轴 | 内容 | 既有机制 |
|---|---|---|
| **能力**（它会的） | 手艺、记忆库存、任务完成率、触觉经验 | stats 任务完成率、skills、robotd 手感沉淀 |
| **信任**（放权曲线） | 它能自己做什么、什么还等你拍板 | exec policy 三档（ask/auto/trusted）、自发档预算、sensor 学习期转正、批次审批、tripwire |
| **传承**（像你的证据） | 记住的偏好、口味校准、工作方式记忆、人格 | approve-and-remember、taste 校准投影（含漏报指标）、mem、persona |

**放权曲线**：把散在配置里的放权点收成一条"自主权边界"读数——今天哪些
事它自己定了（decision=auto 留痕已有）、哪些还等你拍板、学习期还有几天
转正。边界只在用户显式调整时移动，**绝不自动放宽**。

**传承清单**：只呈现"记录在案 + 可点开看出处"的证据链（哪次审批、哪条
记忆），**永不做"相似度 87%"类假指标**（数据诚实红线）。

### 4.3 成长相长交互（零新机制，语言重述；双向）

| 方向 | 交互 | 既有机制 |
|---|---|---|
| 用户 → 它 | 布置：任务书=共同的验收标准 | 收口契约（VerifyDeliverables） |
| 用户 → 它 | 批改：审批 + "依据"行 | theater §16.6 |
| 用户 → 它 | 纠错：`undo --because` → taste 归因投影 | perception Phase 4 |
| 用户 → 它 | 示范：robotd 观察模式（"只许看不许动"） | perception Phase 5 |
| 用户 → 它 | 放行：学习期转正评估 | perception §6 |
| 它 → 用户 | 代决省心：decision=auto 留痕可溯 | policy auto 档 |
| 它 → 用户 | 反哺建议：阈值/预算的校准建议（带证据） | taste 校准证据面 |
| 它 → 用户 | 风险先知：预算/健康的内感受先说 | sensor/self（免准入豁免） |

### 4.4 分身伦理（钉死）

1. **归因不可撤销**：它替用户外发时，收件方永远可辨是"它"不是用户
   （来源前缀与 outbound 纪律已有，分身期不豁免）；
2. **放权可逆**：自主权边界任何时刻可收紧，即时生效，调整落轨迹留痕；
3. **成长不可自我加冕**：阶段迁移的唯一触发是用户放权动作，模型不得
   自行宣称出师——与"模型单方面宣告完成不被采信"同一哲学。

## 5. 传记篇：时间望远镜（收编第一轮）

- **缩放即时间旅行**：滚轮/捏合在舞台（与日记页）上连续拉远拉近，不切页面；
  五档：此刻舞台 → 1h 步骤粒子（显微镜=泳道）→ 24h 生命线 → 14 天年轮
  （=章节回看，周报管道同源）→ 星系（多心智，归容器篇）；
- **右缘时间刻度尺常驻**（此刻→1h→24h→14 天刻痕，hover 预览），缩放永远
  可预期；`prefers-reduced-motion` 下退化为离散档位切换；
- **审计精度不减**：`?step=`/`?run=` 深链语义一个不改；泳道作为显微镜档
  保留 TimelineView 全量能力——宁可缩放保守，不拿审计精度换诗意；
- 回看模式、分集、摘要、年轮条、生命线被此轴**收编**（功能点一个不丢，
  入口归一）。

## 6. 容器篇：居所与零 tab

### 6.1 砍 tab 行

- 舞台自持整窗（自配拖动层+窗控三钮——theater §17.6 窗口管理检查通过）；
- **⌘K 命令面板升格为正式一级入口**：全部路由、身份切换、搜索、新建任务；
- 低频管理（运行四页/感知配置/设置三页）= **X 光透视**：在舞台按 X，宇宙
  切换为线框叠加读数（思考者=轨道飞行器、预算=大气层、传感器=挂图器官），
  再按返回；必须表单化的（providers/env/凭据）收进工作台抽屉。审计能力
  全保留，管理页面消失。

### 6.2 工作台重生为同行面

第一屏回答"**今天我们互相成就了什么**"：共同成长账三栏——它为用户做的
（代决记录 decision=auto 今日清单、自愈事件）、用户为它做的（批改/纠错/
示范/放行）、一起长出来的（新手艺/新偏好/默契）。N 具心智 = 一张同行总表
（谁在起步期、谁快到同行期了）。批量操作收 ⌘K。

### 6.3 对话即养育

高频照护走对话：加感官=对它说"帮我盯着这个目录"（它经审批提案——
perception Phase 1 上手机制已有种子）；预算快到它先说（E1 前兆已有）。
表单只留必须表单的。**从"我去设置页找开关"变成"它把开关递到我面前"**。

## 10. 决策点裁决（2026-10-15 落案，实施以此为准）
