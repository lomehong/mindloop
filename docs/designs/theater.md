# 体验架构：「剧场」v2 — 从此刻到时间线

状态：**v2 定稿（2026-10-13 用户确认）**——三视角头脑风暴打磨 +
Agent UI 前沿调研校准（docs/research/agent-ui-frontier.md），
五个决策点已裁决（§15），调研增补八条已并入（§16）。
v1（同文件前身）确立了双隐喻（观测台+剧场）、舞台四层、全局审批层；
v2 不推翻骨架，补上头脑风暴收敛出的结构性缺口。

三份头脑风暴输入：交互 IA 攻击稿（对话单真相源/密度分区/三入口职
责表/记忆式落地）、视觉动效稿（心智五态宇宙参数/事件舞台叙事/卡片
动效契约/生命感细节）、操作员日常走查稿（隔夜账卡/工作心跳行/在场
芯片/回看模式）。全文引用处标注 [A]/[B]/[C]。

---

## 0. v2 主轴：时间维度与在场

三视角独立收敛到同一诊断——**v1 把「此刻」设计得很好，但时间缺席**：

- 隔夜回来：昨夜 3 报告、1 审批超时、2 线索进展——TTL 过期后舞台
  空空如也，操作员面对的是空白而不是「昨夜战报」；
- ada 自主工作 30 分钟：偶发一瞥只见单卡 morph，没有「它一直干着」
  的累积读数；
- 人离开电脑：inform 类事件要么丢、要么积压成洪峰——系统没有
  「在场」概念；
- 一周后回看：轨迹是流水账、舞台是瞬时的，两者都答不了「这周它
  都干了什么」。

**v2 主轴：给舞台装上时间感**——隔夜账卡（回来看）、工作心跳行
（干着看）、在场芯片（离开管）、回看模式（回头查）。全部投影端实
现，零协议破坏性变更（[C] 总评：五条提案全部可用既有数据源实现）。

## 1. 继承与不变（v1 → v2 稳定部分）

- 双隐喻调和：观测台（引擎室，年轮 v0.3）+ 剧场（舞台，本文）；
- 舞台四层：宇宙氛围 / 场景卡片 / 对话 / 线索；
- 全局审批 confront 卡（任何视图弹出）+ 工作台/任务页既有审批提示
  保留，三处共示同一待批队列；
- Scene Protocol 已就绪：卡片声明 / manifest 回注 / intent 回流 /
  choreography batch；
- 红线不变：core 无像素控制、celebration 禁令、reduced-motion 降级。

## 2. 舞台分区制与密度仲裁 [A2]

卡片不自由浮动。舞台固定三区：

| 区 | 内容 | 规则 |
|---|---|---|
| **中央** | confront 独占（遮罩），同刻至多一张 | 已有约束，升为分区制一条 |
| **右列** | inform/ambient 卡，**至多 3 张可见**，intent 强度+新近排序 | 溢出折叠为列底「还有 N 项 ⌄」聚合 chip，点击展开列表；新卡进场时最旧 inform 卡降为单行摘要条 |
| **底部** | 对话气泡 + 线索行 | **永不参与折叠** |

choreography batch（§4.2 已有）保证同帧多事件单帧落位——分区制是
呈现语义，协议层无需再仲裁。

## 3. 对话单真相源 [A1，裁决 v1 决策点 2]

**删独立对话 tab**。舞台底部输入条右侧「⤢ 展开」→ 全屏浮层对话
（复用 confront 遮罩语言，宇宙层压暗 30%——追光给对话），内含现
chat 页全部能力（目录/历史/深链）；Esc 或「收起」回 3 气泡摘要；
旧 /chat 路由重定向到「舞台+展开态」，书签不失效。

理由（v1 诊断 T3 的自我裁决）：双入口并存是保留病灶。chat 页组件
照搬只改壳，成本 / 低。

## 4. 三入口职责表 [A5]

| 入口 | 职责 | 边界 |
|---|---|---|
| **引擎室抽屉** | 「此刻状态」只读读数：最近 5 条轨迹、在途任务、记忆计数 | 保留「全屏 →」跳转；**禁止内联操作**；v1 的 40% 宽六面板瘦身版被否决（异质面板共享滚动列，扫视成本高于 tab 行） |
| **命令面板** | 低频+全局：身份切换、任意路由、ui set 模板、全文搜索 | 键盘党入口 |
| **舞台** | 高频+本身份：对话、审批、卡片 intent | 不做跨身份 |

碰撞案例裁定：查历史轨迹走面板搜索（全量），不看抽屉（抽屉只有
最近 5 条）。

## 5. 落地页 [A6，裁决 v1 决策点 1]

**记忆式落地**：落地 = 上次会话最后停留的视图（工作台或某舞台）；
首次使用恒落工作台。任何落地页顶部常驻「需要你」行动条（工作台
attention 条升格为全局组件）：待审批 > 0 / 预算 ≥ 80% / stalled /
未决 confront——点击直达。开屏确定性 + 全局注意力一处呈现。

## 6. 隔夜账卡 [C1a/C1b]

打开时距上次活跃 > 4h → 舞台顶部钉 **digest 卡**：

```
昨夜 · 3 报告完成（叶绿）· 1 审批超时（琥珀）· 2 线索进展（星蓝）
├ 每行一句话 + 下钻（报告→轨迹产物、线索→thread 卡）
└ 审批超时行带「重新提交审批」（choice 卡按原脚本重新入队列）
```

- 数据同源工作台「需要你」（fetchApprovals/fetchActivity），10 秒
  扫完；dismiss（intent v2）收起；
- 解决「ambient TTL 1h 过期后隔夜信息洪峰无处安放」的缺口。

## 7. 工作心跳行 [C2]

舞台底部 worklog 行上方加一条 mono 读数：

```
工作中 · 23 min · 第 47 步 · 2 在途
```

随任务弧同步呼吸；hover 弹最近 3 条动作一行流。数据：wakeTask 分
段账本 + 轨迹 tail。配合触达纪律：工作中 ambient/inform 永不弹层、
只允许 confront 打断。

## 8. 在场芯片 [C3]

舞台右上（引擎室旁）presence 芯片「在座 / 离开」：

- **离开** = inform 及以上镜像推企微（审批已有渠道，inform 走同管
  道摘要），ambient 抑制；回来时自动合成隔夜账卡（与 §6 同一合成
  器，窗口不同）；
- presence 落轨迹（intent v2 同类），policy 可读；
- talk PWA 布局一字不动——手机看状态靠企微推送。

## 9. 回看模式 [C4]

舞台右上「回看」→ 选近 7 天 → SurfaceLayer 切为**只读章节视图**：
每张完成的任务、关闭的线索、推送的报告一张卡（时长 · 步数 · 本周
你做过的审批决定），文案复用 ada 既有周报生成管道（同源数据，应用
内同步可见）；每卡底部「查看轨迹 →」深链进引擎室全屏审计。

分工钉死：**舞台管叙事章节（它做了什么），引擎室管步级账本（每步
怎么做）**。

## 10. 心智五态的宇宙表达 [B1]

核心球提炼为一组连续参数（emissive/自转/呼吸周期/色温/星漂），态
间 800ms lerp，禁止跳变：

| 态 | 亮度 | 转速 | 色温 | 附加 |
|---|---|---|---|---|
| idle | 0.35，呼吸 4.8s | 0.06 | 月光绿 | 星漂 0.004；思考者灰 |
| working | 0.75，呼吸 1.6s | 0.16 | 现叶绿 | 弧 α .3→.45、弧组旋转加速 |
| 等审批 | 0.65 恒亮＋外圈琥珀慢闪 | **自转停** | 树脂 tint | 思考者相位冻结——屏息等你拍板 |
| 出错 | 常驻仅陶土 tint 15%（5 分钟衰减） | 不变 | 陶土 | 不常驻红 |
| 冷却 | 0.30，呼吸 8s | 0.03 | 青灰绿 | 星空静止；弧褪至 α.08 不消失 |

理由：五态须不读文字可辨——亮度/速度表能量，色温表语义（叶绿=活、
树脂=等你、陶土=受伤），冻结与静止表不可行动；**不靠变红尖叫**
（年轮 §3.3 纪律）。零新增抓取（activity/approval 队列/最近 clay
步骤/预算水位派生）。

## 11. 事件的舞台叙事 [B2]

- **E1 推卡**：卡 enter 前 120ms，核心球朝卡片象限辉光单侧脉冲
  +0.1——说话有身体前兆，卡才是「它推的」；
- **E2 任务完成**：对应轨道弧补满至 2π（400ms ease-out）→ 一粒叶
  绿光点沿环巡视一圈（600ms）→ 环淡出（400ms）；核心呼吸单次加深
  ×1.5；progress 卡同帧到 100%。**闭合→巡视→熄灭是「收工」句法**，
  一次脉冲替代彩带（celebration 红线不破）；
- **E3 错误**：陶土碎粒自核心近轨弹出又坠回（抛物线 700ms）＋核心
  抖颤一次——伤害是事件不是状态，「疼了一下」而非「坏了」；
- **E4 审批决定**：待批共振环——allow：叶绿闪一次顺时针快扫 300ms
  熄灭；deny：逆时针收拢回核心 300ms 熄灭、参数回落 idle。决策有
  「卸下」的可见瞬间，方向语义相反且可机械断言。

## 12. 卡片动效契约 [B3]

| intent | enter | morph（同 id） | exit |
|---|---|---|---|
| ambient | 400ms ease-out；α 0→0.82；y+8→0；**无缩放**（雾聚） | 内容 crossfade 240ms，不位移 | 400ms 淡出，y−4（蒸发） |
| inform | 320ms cubic-bezier(.2,.9,.25,1)；α 0→1；y+14；scale .97→1 | bar 900ms；高度 FLIP 200ms | 220ms；y−8；scale .96 |
| focus | 360ms；帘幕 clip-path 展开 | 数据淡切 200ms | 240ms 帘幕收合 |
| confront | 遮罩 240ms＋卡 300ms scale .92→1；**宇宙 bloom 压暗 .5→.2** | 不适用（一次一事） | 200ms scale .94＋遮罩同退、宇宙回光 |

batch 多卡 stagger 40ms；reduced-motion 全部退化为瞬时 opacity。
morph 永不位移——数据更新不重演入场。

## 13. 生命感细节 [B4]

1. **闲置微翻身**：idle 超 10min 后每 30–90s 核心随机短促自转
   +0.4°（ease 1.2s）＋呼吸幅度一拍 +0.02——睡着的人会翻身；
2. **预算环的年轮刻线**：每完成一个任务在预算环上留一道 α+0.02 的
   永久亮弧（当日累计、跨天重置）——外环从水位计变成「今天的年
   轮」，读数诚实且有岁月感（与年轮设计系统同名同构）；
3. **在听**：对话输入条 focus-within 时核心辉光 α+0.06、key 光
   +10%（150ms ease，blur 回落）——你还没说话，它先转过头来。

## 14. 实施分期（已确认）

| 期 | 内容 | 验收 |

| A 时间感 | 隔夜账卡 + 工作心跳行（含等待时长）+ 在场芯片（投影端，零协议改动） | 隔夜打开 10 秒扫完昨夜；工作中累积读数可见 |
| B 舞台分区 | 分区制 + 折叠 chip + ambient 沉淀条 + 对话单真相源（删对话 tab） | 8 卡压测不溢出；对话单入口 |

## 15. 决策点裁决记录（2026-10-13 用户确认）

1. **记忆式落地**（§5）：✅ 上次视图落地，首次恒落工作台；
2. **对话单真相源**（§3）：✅ 删对话 tab；
3. **在场芯片的企微镜像**（§8）：✅ 默认关，设置页可开
   （调研印证：ambient 沦为 always-shouting 是最大反模式）；
4. **隔夜账卡 dismiss 语义**（§6）：✅ dismiss 后当天不再合成；
5. **回看模式数据源**（§9）：✅ 复用 ada 周报管道

## 16. 调研校准增补（前沿调研 §4 全文采纳）

1. **等审批态加已等待时长微读数**：心跳行 awaiting 分支显示
   「等你拍板 · 已等 47s」——等待时长是「值不值得打断你」的决策
   输入（assistant-ui elapsed-time 模式）；
2. **ambient 过期第三条路**：TTL 到期不丢弃，**降为单行摘要条**
   沉淀在右列底部（不计 3 张上限），隔夜再合并进账卡——丢 vs 洪
   峰之外的延迟合并；
3. **审批预算控制**：confront 数量由 policy 预算约束——同类动作
   批量确认、低风险转 inform、**记住偏好**（approve-and-remember：
   同类审批二次出现 prefill「按上次决定」，把 97% 批准率带来的
   麻木变成信任资产）——防遮罩独占变成打断工厂；
4. **confront 按风险分级**：支付/删除/外发类强制浮层（Operator
   watch mode 启发），沙箱内动作永不 confront——intent 分级之上
   叠加风险维度；
5. **动效变奏阈值**：同类事件第 3 次起自动降为单行摘要卡，防
   E1-E4 退化为注意力税（与 celebration 禁令同纪律）；
6. **审批卡附「依据」行**：策略组 + 来源任务 + 风险一句话，维持
   信任分辨率；动词写清「谁做什么」（takeover 类语义歧义教训）；
7. **Scene Protocol Phase 3 协议三改**：choreography 帧加
   `batchId`/`staggerHint`（同帧落位可断言）；surface 带
   `exit_reason: ttl|superseded|done|dismissed` 生命周期括号；
   审批回流对齐 interrupt/resume 语义；未知 kind 渲染摘要 fallback；
8. **技术栈定案**：动效 motion（LazyMotion ~34kb）+ 命令面板 cmdk
   + 回看虚拟滚动 TanStack Virtual；宇宙 lerp 手写指数阻尼；全局
   快捷键/通知用官方 Tauri 插件；SSE 手写；**不引入 agent UI
   框架**（与「core 无像素控制」投影式协议不匹配）。

## 17. 实施红线（调研增补，与 §16 配套）

1. **禁止装饰性假状态**：五态参数永远从真实队列派生——宇宙显示
   working 而任务实际 stalled 时，信任崩塌比报错更快；
2. **禁情绪化文案**：不给五态起「难过/着急」类名字——可爱化诱发
   overtrust，思考者抽象雕塑路线保持；
3. **静默卡死禁令**：任何停顿必须有可见状态（心跳行停摆本身要是
   可读信号）；
4. **生成式 UI 不蔓延**：卡片禁止模型自由布局——分区制与
   reduced-motion 契约即失效点，Scene manifest 白名单是底线；
5. **隐喻疲劳监控**：变奏阈值上线后观察退出率，必要时加「动效
   强度」设置档。

## 18. 明确不做（不变 + 新增）

- v1 全部边界照旧（多身份同屏舞台/语音/agent 自由布局/删审计路由）；
- 新增：**不做通知中心**（隔夜账卡与「需要你」已覆盖聚合，独立收
  件箱是过度设计）；
- 新增：**不做实时协作**（单操作员产品）。
