## 2. 方向：「年轮」

### 2.1 概念

**心智观测台 + 田野笔记**。三句话：

- **界面是仪表台**——读数、刻度、格纸（观测台语汇）；
- **轨迹是植物标本**——泳道即生长带，生命线即年轮（有机体语汇）；
- **心智的话是田野手记**——它写的字用衬线，像夹在本子里的手稿。

### 2.2 反 AI-default 校准（Frontend Design 方法）

避开三种默认脸：奶油底衬线陶土、近黑底荧光单色、报纸大标题细线。
年轮的脸是：**腐殖土暖绿黑底 + 叶绿只给"活着与行动" + 五色分类学
只给数据 + 格纸底纹 + 生命线签名**。任何一个屏截出去，都能被认出
是 mindloop。

### 2.3 五色分类学（数据只说五种颜色）

步骤/事件按**语义**归五色，不再按类型散配（现 10+ 生色收敛为 5）：

| 分类学 | 语义 | 步骤类型归并 |
|---|---|---|
| **苔 moss** | 思考 | reasoning / thought / tp-thought |
| **湖 lake** | 观察与外来 | observation / human-msg / operator 发言 / feedback |
| **梅 plum** | 心智之言与结构事件 | message / agent-msg / final / fork / merge |
| **树脂 resin** | 行动与警示 | action / shell / command / 调度触发 |
| **陶土 clay** | 危险与错误 | error / alert / 熔断 |

叶绿（accent）= 单独一层：**生命与成功**（运行中、成功终局、
active 态），不参与分类学。

### 2.4 命名

v0.2 的「Trellis 棚架」不再使用；**v0.3 代号「年轮」**——生命线
一圈一圈叠加在格纸上，是观测对象也是时间本身。仅为设计系统代号
（roadmap §0.2 边界不变）。

### 2.5 结构纪律并入清单（来自 ui-system-v1.md）

1. **唯一骨架 AppShell**：Rail / 内容卡（单头 + 画布 + StatusDock）/
   档案槽——页内不再自绘头部与词标；
2. **六类页面原型**（§7 逐页登记归属），新页面必须声明原型；
3. **组件词汇表**：Button/Chip/Field/Section/StatCard/DataRow/
   Progress/Sparkline/StreamStep/ChatBubble/Empty/LoadingSkeleton/
   ErrorBanner，唯一来源 `components/ui/` 与 `components/`；
4. **状态矩阵**：每组件（默认/悬停/激活/禁用/加载/空）一张表；
5. 其实 4 个待决点 → 本稿裁决，见 §9.1。

## 3. Token 系统 v0.3（唯一来源 `web/static/app/app.css`）

实现直接采用样张逐字色值（`@theme`/`:root` 层；亮暗逐项映射，
双轨对等）。样例名 `--bg` 为文档口径，落到 app.css 时映射到既有
shadcn 变量（`--background` 等），**存量 `bg-background` 类调用
零迁移**。

实现要点：
- 新增 5 个分类学变量 `--moss/--lake/--plum/--resin/--clay` 与
  `--grid`；`--chart-1..5` 重映射为 苔/湖/梅/树脂/陶土（第三方图表
  卡与存量 chart 调用即随动）；
- `step-colors.ts`（38 处）与 `timeline-palette.ts`（46 处）改为
  单表查分类学变量（§2.3 映射表），删去全部具名色类；
- **状态色归一**：运行/成功=叶绿，警示/压缩=树脂，错误/熔断=陶土，
  空闲/离线=灰（muted）。同一事实全站同一渲染；
- 亮色下 clay 加深（#B34E3A）以满足正文对比度；叶绿在亮色下加深
  为 #46853A。

### 3.2 三声部排版

| 声部 | 字体 | 出现位置 |
|---|---|---|
| **说**（sans） | IBM Plex Sans（既有） | 全部 UI 文案、按钮、导航、操作员的话 |
| **写**（note，新增） | IBM Plex Serif（新增 400/400i/600 woff2，OFL） | 心智写的字：聊天消息、记忆条目、摘要、日志叙述；CJK 回退 Songti SC/SimSun |
| **量**（mono） | Google Sans Code（既有） | id / 数字 / 时间戳 / 路径 / 终端输出 / 词标 |

- 字阶收敛为 6 档：12 / 13 / 14 / 16 / 20 / 28（现混用 9 档）；
- 「写」声部字号 ≥13px（衬线在更小字号下 CJK 回退发虚，样张已
  验证 13–15px 舒适）；
- 亮暗同声部不换字体，只换色。

### 3.3 形与格纸

- 圆角三档：10（控件）/ 12（卡）/ full（芯片/坞）；4px 间距栅格；
- **格纸**：1px `--grid` 横线 + 纵线（`linear-gradient` 法），
  只用于泳道画布与图表区底——是"观测台"的纸感来源，严禁全局铺；
- 危险态不做大红填充，用陶土文字 + 陶土 1px 描边（观测台不尖叫）。

### 3.4 动效

- 120ms 态变 / 200ms 浮层 / 320ms 画布入场；
- 生命线 now-edge 呼吸、working 粒子属于"活着的读数"，保留低频；
- 全部尊重 `prefers-reduced-motion`；不做彩带/庆祝类特效。

## 4. 签名元素：生命线（vital strip）

**每具心智 24 小时的活动痕迹**——全站唯一签名，出现在两处：

1. **生命线（完整版）**：轨迹页页头之下，288 桶 × 5 分钟/桶；
   - 柱高=步骤密度；空段=睡眠/未运行（无柱即无活动，不猜）；
   - 底端标记：陶土刻度=错误/告警步骤，湖色菱形=消息进出；
   - 悬停 scrub：跟随读数条（时间 · 步数 · 类型），点击跳到该时刻
     泳道位置；
   - now-edge：右缘叶绿呼吸点 + 「现在」刻度；
   - 轴标签（时刻）与 coverage 说明在轨道下方一行。
2. **微生命线**：首页身份表「近 14 天」列，每日一柱。

**数据源（后端零改动纪律下）**：
- 完整版由轨迹页已载入的 mindlog 窗口（`useMindlog` tail 1000 步）
  推导：窗口覆盖 ≥24h 时严格 24h 轴；不足（超活跃心智）时轴自适应
  并在左缘标注覆盖起点（真实的读数，不假造柱）。`loadOlder` 载入
  更多后自动延长；
- 微版 v1 用 `/usage` 的 `daily[]`（**日粒度**，近 14 天）：柱=当日
  有运行，空=休息。**与样张的差异记录在案**：样张微版画的是小时级，
  实施 v1 为日级（数据诚实优先）；小时级微版与全站 24h 数据端点
  一起列入远期候选（§10）。

**样张与实施的声差**：样张完整版的中段峰值/标记为演示数据，实施
一律取自真实窗口。

## 5. 骨架：三栏不变，视觉重塑

```
┌────────┬──────────────────────────────────┬────────┐
│  Rail  │  内容卡                           │ 档案   │
│  232px │  ┌────────────────────────────┐  │ 280px  │
│        │  │ masthead：生物 · 身份 · 状态 │  │ 身份档案│
│  词标   │  │          · 上下文动作       │  │ /系统  │
│  新的任务│  ├────────────────────────────┤  │ 面板   │
│  工作区 │  │ tab 行：6 tab + 尾随段       │  │        │
│  （身份）│  ├────────────────────────────┤  │        │
│  系统   │  │ 画布（按原型填充）           │  │        │
│  操作员 │  ├────────────────────────────┤  │        │
│        │  │ StatusDock 30px             │  │        │
│        │  └────────────────────────────┘  │        │
└────────┴──────────────────────────────────┴────────┘
```

- **内容卡单头制**：masthead 是唯一页头（生物小像 + 身份名 + 状态
  芯片 + 右侧上下文动作）；**全部页内自绘头部删除**（mindlog2 的
  页内词标、talk 的品牌头不动——talk 独立）；
- **左栏 = 纯切换器**：身份列表只有 [状态点 + 名字]，不携带步数/
  读数/动作（切换归左栏，读数与待办归工作台，见 §5.1）；身份页高亮
  当页身份，工作台上无身份高亮（此时档案栏显示系统面板）；视觉上
  **与窗口同底（--bg）、无右边框**——不做成独立面板，靠激活块与
  悬停自证结构；
- **tab 行**：6 个 tab + 尾随段（随页变化）——轨迹=视图切换段
  （泳道/日志流/分集），运行/设置=子页段，对话/记忆=搜索；
- **档案槽**：身份页=身份档案（体征/代谢/思考者/最近记忆/来源），
  首页=系统面板；窄屏（<1100px）隐藏；
- **StatusDock**：保留，读数统一（运行态 · 端口 · 预算 · 版本）；
- 壳内（`inShell`）与浏览器直开同构；`petMode`/`talkMode` 无 Rail
  的优先级逻辑保持不变；**壳内访问 `/talk*` 一律导回桌面等价路由**
  （手机面只在浏览器/PWA 里呈现）。

### 5.1 首页再定位：从身份名单到「工作台」（2026-10-05 深想）

用户质疑：左栏已能切换身份，身份页是否多余？深想裁决——**保留页面，
重定职责**；「删除并把 / 重定向到最后活跃身份」被否决，因为三件事
将无家可归：

1. **需要你**：待审批、预算水位、熔断冷却、活动 stalled——跨身份的
   注意力事项，左栏一行名字承载不了；跳转式开屏会把它埋进某一具
   身份内部，等你去点开才知道；
2. **批量操作**：新建 / 导入 / 导出全部 / 全部停止需要总控面；
3. **开屏确定性**：应用打开落在哪里？redirect 到「最后活跃」是惊喜
   不是纪律。

职责拆分：**左栏 = 你是谁（切换）；工作台 = 发生了什么事、要我做什么
（读数与待办）**。工作台结构（样张 t-home）：

- **需要你**（全站唯一告警面）：四类信号聚合——待审批 > 0（琥珀）·
  预算 ≥ 80%（树脂）· 熔断冷却中（黏土）· 活动 stalled（黏土）；
  每行 = 身份 + 一句话 + `去处理 →`（跳该身份的桌面任务 tab
  `/i/:id/tasks`）；无
  事项时退化为一行安静的「没有需要你的事」，不占版面；
- **心智卡网格**（≤6 具 3 列；更多时降级列表行）：小像 + 名 + 状态
  芯片 / 最近活动行（“6 分钟前有活动 · 思考者 1/2 忙碌”）/ **14 天
  年轮条**（有柱 = 那天有调用；现台账只记调用与 token，运行计数
  缺席，读数如实写「今日调用」）/ 今日读数（token · 调用次数 · 调度器，
  mono）/ 动作 [进入轨迹 → · 对话 · 停止|启动 · ⋯]；
- **数据全部来自既有 fetch**（后端零改动）：`fetchApprovals` 待审批 ·
  `fetchUsage` daily[] 年轮与 admission 预算/冷却 · `fetchActivity`
  stalled · `fetchIdentities` live/thinkers；启动/停止 = 既有 thinkers
  启停 API；⋯ = 日志/导出；
- **读数下沉**：步数这类纯计数从左栏移除（它属于身份档案），卡上只留
  「现在」相关的读数——同一事实只有一处渲染。

## 8. 状态与文案规范

- **Loading**：骨架条/骨架卡（数值处用灰条脉冲），删除页面级
  「转圈等到底」——19 页的散装 loading 由统一 `LoadingSkeleton` 收编；
- **Empty**：仪器式空态=一句人话 + 一个动作（沿用 Empty 组件语义，
  重刷皮肤）；例：「暂无轨迹 · 尚未产生步骤，启动该身份后出现」；
- **Error**：内联 `ErrorBanner` + 重试按钮（禁无限 spinner）；查询
  静默失败类（档案/系统面板）维持"退化为无读数"纪律；
- **危险/成功对比度**：亮色 clay 用加深值；成功=叶绿；不叠红绿
  相邻大色块；
- **文案声部**：界面话=第二人称、祈使、短（「说点什么…」「停止」）；
  心智内容保持其自有声部（衬线渲染），界面不得改写心智措辞；
- Markdown 渲染：散文段落 → 写声部；表格/代码/数字 → 量声部；
  标题层级克制（消息内不放大标题）。
