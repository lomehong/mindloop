mindloop 系统架构

Go 持久化 AI Agent 框架 · 三进程共享轨迹事实源 · Windows 一等公民（Job Object 沙箱）· 参考 Headlong

三进程 · 零进程内依赖

  • • mind：dispatcher 调度器 + monolith/responder 思考者，活性由 watchdog 与 backoff 驻留保证
  • • connector：渠道无关桥，企微 / WebSocket 双向接入
  • • web：仪表盘 API + React SPA，经控制面文件协议驱动心智
  • • 进程间只共享轨迹文件，目录锁保证多写者安全

轨迹即唯一事实源

  • • 追加式 JSONL，读者各持 cursor，冷启动从 EOF 起步绝不重放
  • • 背压二分法：人类消息 FIFO（上限 16 丢最旧），其余 last-wins
  • • 出站泵三态游标 + 认领地址过滤，投递语义分三档
  • • 身份目录集中 persona / .env / schedule.json / skills / mem

扩展面与渠道

  • • MCP 双向：stdio 客户端接工具服务器，mcp serve 反向暴露为 MCP 服务器
  • • Agent Skills 标准技能库，系统提示渐进披露
  • • schedule.json 定时任务（at / every + quiet 窗口），REPORT_TO 路由到企微
  • • 企微流式回复（打字机）+ 审批卡（button_interaction → policy.Decide）
